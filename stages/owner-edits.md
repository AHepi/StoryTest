# Your edits to stage outputs

The record of the changes you make to what a stage hands you, kept so that a change you keep making can be traced to the stage that keeps needing it. How it is used: `stages/how-stages-work.md`, section 8. One row per change. The agent adds the rows; you never need to. Rows are only added to; a row's last column is updated when its pattern is dealt with.

**Kind** is a few plain words naming what sort of change it was ("made her less articulate", "moved a reveal later", "cut a speech in half"), worded the same way each time the same sort comes back, so that a pattern shows. **Marker** is the marker on the passage you changed (`[from: ...]`), which names the contract step or reference that produced it. **Status** is one of: *one-off* (a change only you could make; nothing else to change), *watching* (could be part of a pattern), *proposed* (a change to a stage was proposed to you: say where), *changed* (in which commit, or which correction), *declined* (you chose to keep editing by hand, and why, if you said).
